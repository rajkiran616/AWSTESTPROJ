# Share on WhatsApp Status & Instagram

Fireworks Diwali greeting (no people). Use the **MP4 videos** below — both apps handle video Status/Stories more reliably than GIFs.

## Files

| File | Best for | Size |
|------|----------|------|
| `diwali-status-stories.mp4` | **WhatsApp Status** + **Instagram Stories** (full-screen vertical) | 1080×1920 |
| `diwali-instagram-feed-whatsapp.mp4` | **Instagram feed post** or WhatsApp chat | 1080×1080 |
| `diwali-whatsapp-status.gif` | Optional GIF fallback | 720×720 |
| `diwali-cover-stories.jpg` | Still cover / thumbnail | 1080×1920 |
| `diwali-cover-square.jpg` | Still feed image | 1080×1080 |

Clips are ~6 seconds and loop-friendly.

---

## WhatsApp Status

1. Save `diwali-status-stories.mp4` to your phone.
2. Open WhatsApp → tap your profile photo (Status) → **Status**.
3. Tap the gallery icon and pick the video.
4. Add text/stickers if you want → **Send**.

Tips:
- Vertical video fills the Status screen.
- If you prefer square, use `diwali-instagram-feed-whatsapp.mp4` instead.
- You can also send either MP4 (or the GIF) directly in a chat.

## Instagram Stories

1. Save `diwali-status-stories.mp4` to your phone.
2. Instagram → **Your story** → pick the video from the gallery.
3. Add music, stickers, or “Happy Diwali” text → **Share**.

## Instagram Feed

1. Save `diwali-instagram-feed-whatsapp.mp4`.
2. Create a new **post** → choose the square video.
3. Write a caption (e.g. “Happy Diwali to friends & family 🪔”) → **Share**.

For a photo post instead of video, use `diwali-cover-square.jpg`.

## Instagram Reels (optional)

Upload `diwali-status-stories.mp4` as a Reel. Add trending audio if you like — keep the clip as-is or duplicate it on the timeline so it plays longer.
